# Lionelraj - Personal Portfolio

Welcome to the source code of my personal portfolio website! This project is a stunning, modern, dark-themed responsive website built using HTML, CSS, and Vanilla JavaScript with a glassmorphism design approach.

**🔗 Live Website:** [https://lionelraj-portfolio.example.com](https://lionelraj-portfolio.example.com) *(Placeholder link: Replace with your actual deployed Vercel/GitHub Pages link)*

## 🚀 Key Features

*   **Glassmorphism UI**: Beautiful, translucent glass card panels with blur effects.
*   **Fully Responsive**: Adapts seamlessly to desktop, tablet, and mobile viewing experiences.
*   **Dynamic Animations**: Includes custom CSS animations (like the floating blockchain graphic and avatar morphing) and scroll-triggered JavaScript fade-ins.
*   **Dark Mode Palette**: A sleek deep-blue and purple aesthetic with glowing cyan and magenta accents.
*   **Interactive Mobile Menu**: A functional and stylish hamburger menu for smaller screens.

## 🛠️ Technologies Used

*   **HTML5**: Semantic and accessible page structure.
*   **CSS3**: Custom variables, Flexbox, CSS Grid, and Keyframe animations.
*   **Vanilla JavaScript**: Lightweight DOM manipulation for scrolling and menu interactions.
*   **Font Awesome**: For iconography.
*   **Google Fonts**: "Outfit" for bold headings, "Space Grotesk" for readable body text.

## 💻 How to Run (Local Development)

Because this website uses plain frontend languages without a server-side framework, it is incredibly easy to view:

1.  Clone or download this repository to your local machine.
2.  Navigate to the project folder (`d:\Lio website`).
3.  Right-click on `index.html` and select **Open with** > **Google Chrome** (or any modern web browser).
4.  *Alternatively, if you are using an IDE like VS Code, you can use the "Live Server" extension to preview the site with hot-reloading.*
